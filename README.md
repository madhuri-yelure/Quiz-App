# Quiz App

A responsive Quiz Application built using HTML, CSS, and JavaScript that presents multiple-choice questions, tracks the user's score, includes a countdown timer, and provides an interactive learning experience.

## Features

- Multiple-choice questions
- Real-time score tracking
- Countdown timer
- Instant result display
- Restart quiz functionality
- Responsive and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Live Demo

https://madhuri-yelure.github.io/Quiz-App/

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
